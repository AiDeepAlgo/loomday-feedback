# LoomDay — משוב מטסטרים

כאן מרכזים תקלות, רעיונות ובקשות לשיפור באפליקציית LoomDay ל־Android.

**המאגר ציבורי.** כל דיווח, תגובה וקובץ מצורף גלויים לכולם. אין לפרסם כתובות דוא״ל, סיסמאות, טוקנים או מידע אישי. בדקו וטשטשו גם צילומי מסך ולוגים לפני העלאה.

## שליחת משוב

**ללא חשבון GitHub:** [שלחו משוב דרך טופס Google](https://forms.gle/DXjM1YGpavqRd7RQA).

1. חפשו קודם ב[דיווחים הקיימים](https://github.com/AiDeepAlgo/loomday-feedback/issues). אם מצאתם את אותה תקלה, הוסיפו פרטים שם.
2. [פתחו דיווח חדש](https://github.com/AiDeepAlgo/loomday-feedback/issues/new/choose) ובחרו **דיווח על תקלה** או **בקשה לשיפור**. נדרש חשבון GitHub.
3. תארו נושא אחד בכל דיווח. עברית ואנגלית מתקבלות.

דיווחים מטופס Google עוברים מיון ידני; הצוות בודק פרטים, מסיר מידע אישי ופותח או מעדכן כאן Issue מתאים. **אין העברה אוטומטית מ־Google Forms ל־GitHub.**

## מה קורה לדיווח?

| מצב בלוח | המשמעות |
| --- | --- |
| חדש | התקבל וממתין לבדיקה ולתעדוף. |
| בטיפול | מתבצעת בדיקה או עבודה על הנושא. |
| מוכן לבדיקה | יש שינוי לבדיקה; ב־Issue יצוינו הגרסה והפעולות שכדאי לבדוק. |
| נסגר | הטיפול הסתיים, או שנסגר עם הסבר, למשל כפילות. |

אם התקלה חוזרת, הגיבו לדיווח הקיים וציינו את גרסת האפליקציה. מעבר ל״מוכן לבדיקה״ אינו אישור שהתקלה נפתרה אצל כל הטסטרים.

## פרטים שעוזרים

בתקלה: מה קרה, איך להגיע אליה, מה ציפיתם שיקרה, גרסת LoomDay, דגם המכשיר, גרסת Android ותדירות התקלה. אפשר לכתוב ״לא ידוע״ כשאין לכם פרט מסוים.

צילומי מסך ולוגים הם **רשות**. יומן האבחון זמין דרך התפריט במסך **היום / Today**; בדקו את תוכנו והסירו מידע אישי לפני שיתוף. אפשר לדווח גם בלי לוג.

[הנחיות לדיווח ולמיון](CONTRIBUTING.md)

## היקף המאגר

זהו מאגר משוב ומעקב בלבד. קוד האפליקציה מנוהל בנפרד ב־GitLab ואינו מתפרסם כאן. אין צורך להעלות קוד, גיבוי אישי או קובץ התקנה כדי לדווח.
